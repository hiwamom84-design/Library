## 💡 ڕاوێژ و پێشنیارە گرنگەکان بۆ سەرکەوتنی ماڵپەڕەکە (Website Advices)

1. **پێشبڕکێی مانگانەی خوێندنەوە (Reading Challenges)**:
   - سوود لە تایبەتمەندی «چەند کەس خوێندوویەتیەوە» وەربگرە بۆ دیاریکردنی «خوێنەری مانگ» لەناو منداڵان یان ئەندامانی خێزان و خەڵاتکردنیان.

2. **کوالیتی وێنە لە مۆبایلەوە**:
   - کاتێک بە کامێرای مۆبایل وێنەی بەرگی کتێب دەگریت، هەوڵبدە لە شوێنێکی ڕووناک بێت و ڕاستەوخۆ لە سەرەوە وێنەکە بگریت تا بەرگەکە جوان و سەرنجڕاکێش دەربکەوێت.

3. **بەستنەوە بە کۆدی QR**:
   - دەتوانیت لە ڕێگەی پرینتەرەوە کۆدی کورت بۆ هەر کتێبێک دروست بکەیت و لەسەر بەرگی کتێبە فیزیکییەکان بیدەیت لە ماڵەوە، تا هەر ئەندامێک بە مۆبایل سکانی بکات ڕاستەوخۆ پەڕەی کتێبەکەی بۆ بکاتەوە.

4. **پشتگیری و نوێکردنەوەی بەردەوام**:
   - بنکەدراوەی PostgreSQL هەموو داتاکانت دەپارێزێت؛ هەفتانە یان مانگانە کتێبی نوێ بەپێی قۆناغەکان زیاد بکە تا هەمیشە کتێبخانەکە نوێ بێت.

## 💻 شێوازی کارپێکردن لە Visual Studio

```bash
# 1. دامەزراندنی پاکێجەکان
npm install

# 2. دروستکردنی خشتەکانی بنکەدراوە
npm run migrate

# 3. دروستکردنی بەڕێوەبەر بە تێپەڕەوشەی 1234554321
ADMIN_PASSWORD="1234554321" npm run setup-admin

# 4. دەستپێکردنی سێرڤەر
npm start
```
ماڵپەڕەکە لەسەر `http://localhost:5000` دەکرێتەوە.
